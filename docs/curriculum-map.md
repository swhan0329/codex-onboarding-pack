# Curriculum Map

## Learning Promise

Learners should finish with a practical mental model of Codex and at least one reusable workflow artifact.

## Initial Skills

| Skill | Purpose | Output |
| --- | --- | --- |
| `codex-camp-start` | Route the learner into the right track and keep language consistent. | Selected learning path and next skill invocation. |
| `codex-day1-core` | Explain Codex's main surfaces and extension points through small exercises. | `CODEX_ONBOARDING_MAP.md` or a paste-ready equivalent. |
| `codex-day2-skills` | Teach skill authoring by turning a daily workflow into a reusable skill. | `.agents/skills/my-first-workflow/SKILL.md` draft. |

## Suggested Expansion

- Day 3: `codex-day3-plugins-mcp` for plugin packaging and MCP connections.
- Day 4: `codex-day4-subagents-review` for parallel review, validation, and review loops.
- Day 5: `codex-day5-capstone` for a personal or team daily workflow.

## Design Rules

- Teach by doing, not by listing product features.
- Keep every block to one small action.
- End each Phase A with a direct practice instruction, then stop.
- Ask the learner to reply "done", "next", "완료", or "다음" before continuing.
- For Korean learners, use the pattern: English term -> Korean meaning -> why it matters -> easy example.
- For English learners, keep official English terms and give concrete examples.
