# Block 1: Workflow Design

## EXPLAIN

Korean:

좋은 스킬은 "설명문"이 아니라 "실행 순서"입니다. Codex가 읽고 바로 움직일 수 있도록 입력, 절차, 검증, 출력 형식을 분리합니다.

English:

A good skill is not an essay. It is an executable workflow: inputs, procedure, verification, and output format.

## EXECUTE

Turn the chosen task into this brief:

```md
# Skill Brief

## Job

## When to trigger

## Inputs Codex should inspect

## Steps Codex should follow

## Verification

## Output format

## Boundaries
```

## CHECK

Good answer:

- Uses imperative steps.
- Names what should be inspected.
- Includes a final check.
