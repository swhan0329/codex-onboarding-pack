# Block 5: Wrap

## EXPLAIN

Korean:

좋은 결과물은 "Codex 기능을 안다"가 아니라 "내 업무에 어떤 표면을 쓰면 되는지 설명할 수 있다"입니다.

English:

The useful output is not "I know Codex features." It is "I can choose the right Codex surface for a real task."

## EXECUTE

Create or help the learner draft this artifact:

```md
# Codex Working Notes

## My current Codex surface

## Core feature map

| Feature | What it is | When I should use it | Example in my work |
| --- | --- | --- | --- |

## My daily workflow candidates

## Verification habit
```

If writing files is appropriate, save it as `CODEX_WORKING_NOTES.md`. Otherwise, provide it as paste-ready Markdown.

## CHECK

Good answer:

- Includes one real workflow candidate.
- Separates Skill, Plugin, MCP, Subagent, Hook, and AGENTS.md.
- Includes a verification habit.

## CONTINUE

After the notes are drafted, do not end the onboarding. Recommend one of these:

- Test the notes on one real Codex task.
- Turn one repeated workflow into a Skill with `codex-skill-builder`.
- Revisit the extension map to decide whether MCP, Plugins, Subagents, Hooks, or AGENTS.md are needed.
