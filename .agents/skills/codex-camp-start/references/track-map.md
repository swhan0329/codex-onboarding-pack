# Track Map

## Korean Menu

Codex 온보딩을 시작합니다.

목표는 기능을 외우는 것이 아니라, Codex로 실제 작업물 하나를 남기는 것입니다.

어떤 방식으로 시작할까요?

1. 빠른 체험: Codex 핵심 기능 지도를 20분 안에 훑기
2. Daily workflow: 반복 업무 하나를 Codex 흐름으로 바꾸기
3. Skill builder: 내 첫 `Skill (스킬)` 만들기
4. Facilitator mode: 수업/워크샵 진행안 만들기

답장 예시: `1`, `빠른 체험`, `Daily workflow`, `Skill builder`

## English Menu

Welcome to Codex onboarding.

The goal is not to memorize features. The goal is to leave with a concrete workflow artifact.

How would you like to start?

1. Quick tour: map the core Codex features in about 20 minutes
2. Daily workflow: turn one recurring task into a Codex workflow
3. Skill builder: create your first Codex Skill
4. Facilitator mode: create a workshop run-of-show

Reply with: `1`, `quick tour`, `daily workflow`, or `skill builder`.

## Routing

- Quick tour -> `$codex-day1-core`
- Daily workflow -> `$codex-day1-core`, then `$codex-day2-skills`
- Skill builder -> `$codex-day2-skills`
- Facilitator mode -> read `facilitator-guide.md`
