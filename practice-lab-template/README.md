# Codex Practice Lab

이 폴더는 Codex를 손으로 익히기 위한 더미 작업 공간입니다. 실제 고객 정보, API key, 비밀 문서는 들어 있지 않으니 안전하게 읽고, 고치고, 검증해볼 수 있습니다.

This is a small fake workspace for learning Codex by doing. It is safe to edit, break, summarize, and reorganize.

## 먼저 열어볼 파일

- `START_HERE.ko.md`: 한국어 실습 안내
- `START_HERE.en.md`: English practice guide
- `prompts/01-first-task.ko.md`: 첫 번째 복사/붙여넣기 프롬프트

## 해볼 수 있는 일

1. 회의 메모를 읽고 action item 표로 정리하기
2. 어색한 공지 초안을 더 자연스럽게 다듬기
3. 작은 JavaScript 버그를 찾아 고치고 검증하기
4. CSV 데이터를 짧은 상태 보고서로 요약하기
5. 반복할 만한 업무를 Codex Skill 아이디어로 바꾸기

## Start Here

Open one of these prompt files and copy/paste it into Codex:

- Korean: `prompts/01-first-task.ko.md`
- English: `prompts/01-first-task.en.md`

Each prompt should point you to the next prompt file so the practice loop does not stop after one answer.

## Ground Rules

- 모두 더미 데이터입니다.
- 실제 API key, 고객 정보, 사내 문서는 넣지 마세요.
- 작은 변경부터 요청하세요.
- Codex에게 무엇을 바꿨고 어떻게 확인했는지 꼭 말하게 하세요.
