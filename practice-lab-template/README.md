# Codex Practice Lab

This is a small fake workspace for learning Codex by doing. It is safe to edit, break, summarize, and reorganize.

이 폴더는 Codex를 손으로 익히기 위한 더미 작업 공간입니다. 실제 고객 정보, API key, 비밀 문서는 들어 있지 않습니다.

## What You Can Try

1. Read messy notes and make an action-item table.
2. Improve a rough announcement draft.
3. Inspect a tiny JavaScript bug and fix it.
4. Summarize CSV data into a short status report.
5. Turn one repeated workflow into a Codex Skill idea.

## Start Here

Open one of these prompt files and copy/paste it into Codex:

- `prompts/01-first-task.ko.md`
- `prompts/01-first-task.en.md`

Codex should read files in this folder, do one small task, and then suggest the next exercise.

## Ground Rules

- This is dummy data.
- Do not add real secrets.
- Prefer small changes.
- Ask Codex to show what it changed and how it checked the result.
