# Prompt 01: 첫 번째 Codex 실습

아래 내용을 Codex에 복사해서 붙여넣어보세요.

```text
이 `codex-practice-lab` 폴더를 처음 보는 사용자라고 생각하고 도와줘.

먼저 `README.md`와 `inbox/meeting-notes.md`를 읽어줘.

파일은 아직 수정하지 말고, 채팅에만 아래 형식으로 답해줘:

1. 이 폴더에서 해볼 수 있는 일 3가지
2. 회의록에서 나온 action item 표
3. 다음 실습으로 열 파일: `prompts/02-edit-draft.ko.md`
4. 이 작업을 검증하려면 무엇을 확인하면 되는지

중요:
- 다음 프롬프트를 새로 만들지 말고, 반드시 `prompts/02-edit-draft.ko.md`를 열어 이어가라고 안내해줘.
- 답변 마지막에는 `다음은 prompts/02-edit-draft.ko.md를 열어 복사/붙여넣기 해보세요.`라고 적어줘.
```
