# Start Here

This practice folder is a safe dummy workspace for learning Codex without starting from a blank screen.

Open this file and copy/paste the prompt into Codex:

```text
prompts/01-first-task.en.md
```

Practice sequence:

1. Read meeting notes and make an action-item table.
2. Improve a rough announcement draft.
3. Fix and verify a tiny JavaScript bug.
4. Summarize CSV data.
5. Turn a repeated task into a Skill idea.

Each exercise should point you to the next prompt file.
