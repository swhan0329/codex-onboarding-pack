## Product Distinction

- Skill: the workflow instruction.
- Plugin: the installable bundle.
- MCP server or app connector: access to live external tools or private workspace data.
- AGENTS.md: durable project rules.
- Hook: deterministic lifecycle automation.
- Subagent: parallel delegated agent work.
