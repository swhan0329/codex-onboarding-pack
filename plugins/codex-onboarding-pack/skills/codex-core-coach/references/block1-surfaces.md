# Block 1: Codex Surfaces

Official references:

- https://developers.openai.com/codex/app/features
- https://developers.openai.com/codex/cli
- https://developers.openai.com/codex/ide

## EXPLAIN

Korean:

- Codex app: 여러 프로젝트와 스레드를 관리하고, 브라우저/워크트리/자동화까지 함께 쓰기 좋은 데스크톱 표면입니다.
- CLI: 터미널에서 현재 repo를 직접 다루는 표면입니다.
- IDE extension: 열어둔 파일과 선택한 코드를 맥락으로 삼기 좋은 표면입니다.
- Web/cloud: 원격 환경에서 일을 맡기기 좋은 표면입니다.
- In-app browser: 로컬 웹앱이나 공개 페이지를 보며 QA하기 좋습니다.
- Computer Use: Codex가 실제 데스크톱 앱을 보고 클릭해야 할 때 씁니다.

English:

- Codex app: desktop workspace for projects, threads, worktrees, browser checks, and automations.
- CLI: terminal-first work inside a repo.
- IDE extension: editor-attached work with open files and selected code as context.
- Web/cloud: remote or hosted work.
- In-app browser: QA local web apps and public pages.
- Computer Use: operate desktop apps when a task needs visual UI interaction.

## EXECUTE

Use the practice lab as the example. Ask the learner:

Which surface are you using right now: Codex app, CLI, IDE extension, or web/cloud?

Then map that surface to one practice-lab task:

- read `inbox/meeting-notes.md`
- edit `drafts/product-announcement.md`
- fix `project/simple_app.js`
- summarize `data/weekly-metrics.csv`

## CHECK

Good answer:

- Matches the surface to the task.
- Mentions a verification path, such as tests, browser QA, file diff, or manual review.
