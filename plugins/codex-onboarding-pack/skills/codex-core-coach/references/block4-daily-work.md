# Block 4: Daily Work

Official references:

- https://developers.openai.com/codex/workflows
- https://developers.openai.com/codex/plugins
- https://developers.openai.com/codex/app/features

## EXPLAIN

Korean:

Daily 업무에 Codex를 붙일 때는 "큰 자동화"보다 "반복되는 판단과 출력물"을 먼저 찾습니다. 예: 메일 triage, 회의 준비, 리포트 초안, PR 리뷰, 문서 업데이트, 브라우저 QA, 데이터 요약.

English:

For daily work, start by finding repeated judgment and repeated output, not a giant automation. Examples: inbox triage, meeting prep, report drafts, PR review, doc updates, browser QA, and data summaries.

## EXECUTE

Ask the learner to list three recurring tasks using this table:

| Task | Input source | Output | Frequency | Human review needed? | Best Codex surface |
| --- | --- | --- | --- | --- | --- |

Then choose one task to test with Codex. If it should become reusable, route to `codex-skill-builder`.

## CHECK

Good answer:

- Has a clear input and output.
- Happens repeatedly.
- Has a review step.
- Can start small in under 30 minutes.
